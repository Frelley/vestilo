## Tables

### products
| Column | Type | Notes |
|---|---|---|
| id | uuid PK | auto |
| created_at | timestamptz | auto |
| name | text | auto-label: SIZE-NNN (e.g. M-003) |
| cat | text | category |
| size | text | XS S M L XL XXL XXXL |
| color | text | |
| price | numeric(10,2) | default 35, rounds to .99 on blur |
| styles | text[] | |
| status | text | Disponible / Vendido / Reservado / Archivado |
| photo_url | text | legacy single photo |
| photos | text[] | up to 4, first = thumbnail |
| notes | text | internal description (used by PosterModal) |
| ai_tags | text[] | hidden, generated by analyze-product |
| content_themes | text[] | hidden reel-grouping buckets like `cartoon-core`, `anime-core` |
| content_entities | text[] | hidden fandom/IP labels like `harry-potter`, `pokemon` |

## Storage
- Bucket: `product-photos` (public)
- Path: `products/{id}-{timestamp}.{ext}`

## Auth
- Email + password
- RLS: public reads `Disponible` products only; admin reads all

## SQL files
All DDL and RPC functions live in `sql/`:
- `orders.sql` — orders table + RPC
- `search_logs.sql` — search logging table
- `mode_logs.sql` — mode usage logging table
- `add_ai_tags.sql` — adds ai_tags column
- `api/search_products_scored.sql` — scored search RPC (run in Supabase once)
